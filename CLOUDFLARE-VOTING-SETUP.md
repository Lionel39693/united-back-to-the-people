# Public voting setup — adult-supervised launch required

This repository now contains a Cloudflare Pages Functions voting endpoint and D1 schema for the permanent ownership consultation. The vote is NOT live until every step below is completed and tested.

## 1. Create the database
In Cloudflare Dashboard, open **Workers & Pages → D1 SQL Database → Create database**. Use a clear name such as `ubtp-polls`. Open its SQL console and run the complete contents of `schema.sql`.

## 2. Bind it to Pages
Open the Pages project connected to this repository → **Settings → Functions → D1 database bindings**. Add a binding:
- Variable name: `DB`
- D1 database: the `ubtp-polls` database created above

Apply the binding to Production (and Preview only if you intend to test there). Redeploy after changing bindings.

## 3. Add the hash secret
In Pages project → **Settings → Variables and Secrets**, add a Production secret:
- Name: `VOTE_HASH_SECRET`
- Value: a long random secret generated by the adult account administrator. Never put it in GitHub, HTML, or a chat.
Do not use a password or reuse another account secret.

## 4. Deploy and test
Cloudflare Pages must be connected to this GitHub repository, production branch `main`, framework preset **None**, build command blank, output directory `.`. Deploy the latest `main` commit.

Test:
- `/api/results` returns total 0 and three zero counts.
- Submit one test vote and confirm total becomes 1.
- Submit a second vote from the same network; it should be rejected with 409.
- Test on a separate network and check totals.
- Confirm the poll works logged out and on mobile.
- Do not publish launch claims until the adult moderator approves the privacy notice and these tests.

## Privacy and limits
The endpoint never stores a raw IP address. It hashes the Cloudflare-provided network address with a secret and stores that hash to reduce duplicate submissions. A shared home, school, workplace or mobile carrier network may share one response. This is not identity verification, not proof of supporter status, and not a representative vote of all United supporters. Results are aggregate only. The adult administrator must set a retention and deletion policy before launch.

The poll asks for an opinion about ownership. It does not collect names, email addresses, phone numbers, school details or addresses. Do not add those fields.
